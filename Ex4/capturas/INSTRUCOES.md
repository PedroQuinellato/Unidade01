# Capturas de Tela – Exercício 4

Esta pasta deve conter as capturas de tela exigidas por cada produto.

---

## Produto 1 – Conta Azure ativada

**Arquivo:** `01-portal-azure-usuario.png`

Capturar na tela do Portal Azure (https://portal.azure.com) mostrando:
- O ícone/nome do seu usuário no canto superior direito
- Preferencialmente a tela inicial (Dashboard) com os recursos

---

## Produto 2 – PostgreSQL no Azure

**Arquivo (i):** `02-azure-postgresql-recurso.png`

Capturar a tela do recurso "Azure Database for PostgreSQL" mostrando:
- Nome do servidor (URL de conexão)
- Sua conta/assinatura Azure vinculada

**Arquivo (ii):** `03-azure-postgresql-query.png`

Capturar a execução de um SELECT no Query Editor do portal Azure ou
via pgAdmin conectado ao servidor Azure, mostrando:
- String de conexão ou painel conectado
- Resultado do SELECT com dados da tabela

---

## Produto 3 – Language Service (Serviço Cognitivo)

**Arquivo:** `04-azure-language-recurso.png`

Capturar a tela do recurso "Language Service" no Portal Azure mostrando:
- Nome do recurso
- Endpoint (ponto de extremidade)
- Tipo de preço (F0 – Gratuito)
- Sua conta Azure vinculada
